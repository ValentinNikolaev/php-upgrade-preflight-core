# PHP Upgrade Preflight v0.3.4: withheld release candidate

Prepared 2026-10-07. This was a distribution-only candidate, not a completed coordinated release. No monorepo `v0.3.4` tag or GitHub release was published. The corrected release proceeds as [v0.3.5](v0.3.5.md).

## Why publication was withheld

[PR #30](https://github.com/ValentinNikolaev/php-upgrade-preflight/pull/30) prepared the Laravel completion payload and merged as `e38daa4dd7bd9ec906876bc92f95ac71d06db4ba`. The candidate passed its 18-job Quality run, 16-job compatibility matrix, locked dependency audit and non-publishing release rehearsal. The rehearsal deliberately skipped tag-only verification and publication.

Exporting that approved commit through a Docker bind mount on Windows preserved file contents but staged ordinary distribution files as `100755` instead of the source commit's `100644`. The error was found after the three distribution tags had been pushed, before the monorepo release tag. The candidate's ordinary README and Composer manifest modes differ from the authoritative source tree while their blob identities match.

These signed tags remain available and are not overwritten. Automatic package indexing may expose them; prefer the corrected v0.3.5 patch after coordinated publication. Their immutable documentation retains pre-publication wording, including "Released 2026-10-07" in the notes and "latest published release" in the README. Those statements were premature and must not be treated as proof of a completed coordinated release.
